S1.4 — the two checkPlaceholders escapes are deleted, and the gate bites without them
=====================================================================================
Session 2, 2026-08-06. Commit b05efc3. Re-run: `npm run check && npm run build`.


1. WHAT WAS DELETED
-------------------
astro.config.mjs before (the template's two escapes):

    checkPlaceholders({
      collections: editable,
      allow: ["homePage:meta.description", "homePage:meta.ogDescription"]
    })

after:

    checkPlaceholders({ collections: editable })

Both allowed paths were `TODO:` strings in src/content/pages/home.yaml. They now
carry the site's real meta description and og description, so the escapes had
nothing left to escape.

check-placeholders prints nothing on a clean pass, which is why section 3 exists:
a gate that is silent when it passes and silent when it is switched off looks the
same from the outside.


3. THE GATE BITES — DELIBERATE RED, BOTH RULES, NO ESCAPES AVAILABLE
--------------------------------------------------------------------

allowed fields — the template's own TODO in one, a reserved documentation domain
in the other — and the build re-run:

    meta.description   = "TODO: the one-paragraph description search engines show."
    meta.ogDescription = "Write to hello@example.com."

$ npm run build
