  working on the site's own specification.

  A third: Appendix A says 315 sessions "recorded agent tokens". Across the 18
  published runs the store answers 326 sessions with any agent cost row, 325 with

  every rate divides by the 340 and names it.

How it reads the store
----------------------

  Run-level truth      conductor history --json --limit 0
  Everything else      each run.db opened { readOnly: true }, every query
                       filtered by run_id
  Names                anonymise.json; a run with no entry is excluded

  Three traps closed, all of them silent otherwise:

  1. One run.db holds several runs. The store is keyed by repo and plan, and the
     legacy import consolidated runs into shared files - the web fleet's three
     rounds live in one database. An unfiltered count of bugs answers 50 where
     that run filed 23.
  2. sessions.soft_break is 0 for every row in the entire store. Soft breaks are
     events (SoftBreakRequested), not a column. A harvest reading the column
     publishes zero and looks correct.
  3. Checkpoints come from the history JSON. A CheckpointConfirmed event count
     answers 65 store-wide where the engine answers 295 of 328 - re-measured
     here, not taken on trust.

  And one rule enforced rather than documented: refuseBudgetShaped() throws if
  the harvest ever mints a key matching floor / median / wrap-up / *Rate /
  perMillion / blended / nudge / *cap / headroom / tokensPerCheckpoint. Those
  come from `conductor budget` and `conductor money`. The store cannot even see
  a cap - runs.limits_json is NULL for every imported run.

What is excluded, and why that is the interesting part
------------------------------------------------------

  The run that is building this site (f5066ddc) is in the store and is not in
  anonymise.json, so it is excluded - which is why the totals above are the
  corpus as measured and not the corpus plus whatever this session has spent so
  far. Fail-closed is not a special case here; it is the ordinary path, and it
  ran on the first harvest without anybody arranging it.
