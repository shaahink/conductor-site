## The figure this checkpoint had to add first

SPEC Part IV gives concept 2 its evidence as "`costs.category` splits agent $3,015 vs advisor
$0.09". The harvest has always read `costs` grouped by `category` into a `byCategory` bundle, and
never published any of it — so there was no key to cite, and the alternative was typing the
numbers into the prose, which `refuseTypedFigures` correctly refuses.

Measuring it produced a correction to the plan document, which is the site's own first rule
working on the site itself. Across the eighteen published runs the store has **three**
categories, not two, and the advisor figure is not the one the SPEC prints:

| category | measured | SPEC |
|---|---|---|
| agent | `$3,014.80` | ~$3,015 ✓ |
| gate | `$1.26` | not mentioned |
| advisor | `$0.24` | $0.09 ✗ |

All three are now corpus figures — `totalAgentCostUsd`, `totalGateCostUsd`,
`totalAdvisorCostUsd` — recomputed by `npm run harvest` like everything else.

The advisor figure ships with its provenance attached, in the strip and in the page's prose,
because it is the one number on the site that is not metered:
`VerdictEngine.Advisor.cs:34` prices the lane at a flat rate per second of advisor wall-clock.
It is an estimate of something too small for the ledger to have measured, and saying so is
cheaper than being asked.

## Citations resolve

`scripts/citations.mjs` reads every `inConductor.citations` entry in the content, opens the file
it names in a checkout of the engine, and prints the line it landed on. The engine checkout is
never written down in this repo — it comes from `CONDUCTOR_REPO` or the sibling directory,
because this repository is public.

```
citations: 23 across the content, against the engine checkout
engine revision: 1632b9f
...
citations: all 23 resolve at 1632b9f.
```

Full output, including the source line each citation landed on, is in
[`S4.1-citations.txt`](S4.1-citations.txt). The script exits non-zero on a missing file or a line
past the end of one; it deliberately does not try to judge whether the line still *means* what
the note says, which is the reading S4.4 owes.

## Litmus tests, applied

1. **Every number traceable.** Neither page types a figure. Every value above came out of
   `corpus.json`, and `refuseTypedFigures` would have failed the build on any of them written
   into a sentence — including the two-digit counts, which is why both pages spell small
   quantities as words.
2. **The failures are on the page.** `agentic-engineering` names `the-abandoned-prototype`
   beside `the-fleet-round-after`, so the strip prints one run that closed everything it opened
   next to one that stopped partway and is labelled `abandoned` by the strip itself. Its problem
   section is about the loop that believes the agent, and its mechanism section cites the bug
   where scheduling from the plan's declaration re-picked delivered work forever.
   `multi-agent-orchestration` leads its own mechanism with why the advisor must be allowed to
   fail, and ends it by labelling its own estimate.
3. **Useful without Conductor.** Checked mechanically above.
