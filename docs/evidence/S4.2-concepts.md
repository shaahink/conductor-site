## What the corpus actually says about gates

Concept 5 publishes `totalGatesRed`, so the label had to be checked rather than assumed. A gate
row in the store carries `passed`, `skipped` and `optional` separately, and the harvest counts
green as `sum(passed)` — which would quietly fold skipped and cached rows into the same number.
Measured across the eighteen published runs:

```
passed=1 skipped=0 optional=0 : 648
passed=0 skipped=0 optional=0 :  29
```

There is not one skipped gate and not one optional gate in the entire corpus. So the denominator
is entirely required gates, and the twenty-nine are required gates that failed outright — which
is what the page says they are. A cached pass is recorded with `passed` set
(`GateRunner.cs:66`), so cached results sit inside the six hundred and forty-eight, and the page
does not claim otherwise.
