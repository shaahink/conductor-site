## The layout, seen rather than assumed

Screenshots of the built page through `astro preview`, full page, both schemes:
`S6.4-runs-mocha.png` and `S6.4-runs-latte.png`.

Two things only a real page showed, both fixed:

1. **Astro strips the whitespace between sibling elements.** The date, the repo
   key and the status were three inline spans with `white-space: nowrap` and no
   space character anywhere between them, so the row header's *minimum* width
   became the whole meta line set as one unbreakable word — 343px, which pushed
   `spent` and `gates green` off the side of the table. `.meta` is now a flex
   row, whose items wrap between themselves.
2. **The reading measure is wrong for a table.** 62–72ch is how far an eye
   tracks a line; this is read across. Inside the column the table overflowed a
   1280px desktop window and every reader got the scrollbar meant for the
   phone. It now breaks out by `--space-3xl` either side above `64rem` — the
   breakpoint the sticky table of contents already uses. Measured after:
   `scrollWidth 752 === clientWidth 752`, and no horizontal overflow on the
   document at 1280 or at 504.

Below `64rem` the table scrolls inside a `role="region"` `tabindex="0"`
container labelled by the heading, so a keyboard can reach the columns a narrow
viewport pushed off the side.
